## Official file

[`2026-mllm-topics-final.jsonl`](2026-mllm-topics-final.jsonl) contains the 50
final test topics, `MLLM_051` through `MLLM_100`, exactly as downloaded. The
file is 4,317 bytes and has SHA-256 digest
`1261d71134161a9b05a15b872679d1d0a3f1a6fd2465b968e78c5c619bdd54b6`.

The official download requires the TREC participant username and password sent
after registration. Do not commit those credentials.

## Deadline

The organizer's August 17 announcement states that runs are due on
**September 6, 2026, Anywhere on Earth (AoE)**. The submission link had not yet
been shared when these topics were captured.

These queries have hidden judgments. Keep test runs and analysis separate from
development evidence, and do not use the test topics for model selection.
